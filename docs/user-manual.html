Section 1

Introduction

Welcome to the AfDB Project Management System. This secure enterprise portal enables African Development Bank staff to manage projects, coordinate teams, generate reports, and track portfolio activities across member countries.

Before You Begin

Ensure you have your AfDB credentials and access to your email for two-factor authentication.

Key Features

  • Project Management — Create, edit, and track projects across African member countries
  • Team Collaboration — Manage team members, assign roles, and set permissions
  • Reporting — Generate and download comprehensive project reports
  • Security — Enterprise-grade security with MFA, session management, and audit trails
  • Search — Quickly find projects by name, code, country, or sector
Section 2

Getting Started

This section guides you through accessing the system for the first time.

2.1 Login

Access the system by navigating to the login page and entering your credentials.

Eng. Depute
localhost:3001/login
Figure 2.1: The login page (light mode)
Eng. Depute
localhost:3001/login
Figure 2.1: The login page (dark mode)
  1. Open your web browser and navigate to the AfDB Project Management System URL
  2. Enter your email address in the Email Address field
  3. Enter your password in the Password field
  4. Click the Sign In button
  5. If you have two-factor authentication enabled, you will be prompted to enter a verification code (see Section 2.2)
  6. Upon successful authentication, you will be redirected to the Dashboard
Account Security

After 5 failed login attempts, your account will be locked for 15 minutes. Contact IT support if you need assistance.

2.2 Two-Factor Authentication

For enhanced security, the system requires email-based verification after entering your credentials.

Eng. Depute
localhost:3001/mfa
Figure 2.2: Two-factor authentication screen (light mode)
Eng. Depute
localhost:3001/mfa
Figure 2.2: Two-factor authentication screen (dark mode)
  1. After entering your credentials, check your email for a 6-digit verification code
  2. Enter the code in the verification fields (one digit per field)
  3. Click Sign In to complete authentication
  4. If you don't receive the code, click Resend Code to request a new one
Note

Verification codes expire after 10 minutes. If your code expires, simply request a new one.

2.3 Verification Code Email (OTP Inbox)

After requesting a verification code, the system sends an email to your registered email address. This email contains a 6-digit One-Time Password (OTP) that you must enter on the verification screen to complete authentication.

Eng. Depute
localhost:3001/mfa
Figure 2.3: The OTP verification email received in your inbox
  1. Open your email inbox and look for an email from AfDB Project Management System
  2. Open the email to find the 6-digit verification code
  3. Enter the code in the verification fields on the authentication screen
  4. Click Sign In to complete the verification process
Important

If you do not see the email in your inbox, check your spam/junk folder. You can also click Resend Code on the verification screen to receive a new code. Never share your verification code with anyone.

Follow these steps to create a new project in the system.

  1. Click the New Project button on the Projects page
  2. Fill in the required fields:
    • Project Name — The official name of the project
    • Project Code — A unique identifier (e.g., AFDB-2026-001)
    • Country — The member country where the project is located

AI Chat Assistant

The AI Chat Assistant provides instant help with platform navigation, features, and common questions. It combines an intelligent chatbot with the ability to connect you to a live team member when needed.

10.1 Opening the Chat Widget

The chat widget is accessible from any page via the green chat bubble in the bottom-right corner of the screen.

  1. Look for the green chat bubble icon in the bottom-right corner of any page
  2. Click the bubble to open the chat widget
  3. The AI Assistant will greet you with quick-access links and suggested questions

10.2 Asking Questions

The AI Assistant can answer questions about platform features, navigation, settings, and more. Simply type your question or click one of the suggested questions.

  1. Click on the text input at the bottom of the chat widget

Section 12

API Documentation & Health Check

The backend server provides two essential developer endpoints accessible via the sidebar quick-action buttons. These tools help you explore the API and verify system health in real-time.

12.1 API Documentation (Swagger UI)

The interactive API documentation is powered by Swagger UI and available at localhost:4000/api-docs. It provides a complete reference of all available endpoints, request/response schemas, and the ability to test API calls directly from the browser.

  1. Click the API Documentation button (code icon) in the sidebar quick actions
  2. Or open http://localhost:4000/api-docs directly in your browser
  3. Browse available endpoints grouped by controller (Auth, MFA, SSO, etc.)
  4. Expand any endpoint to view parameters, request body, and response schemas
  5. Click "Try it out" to test endpoints directly from the documentation
Note

The API documentation is auto-generated from the backend code. All endpoints listed are live and can be tested with valid authentication tokens obtained from the login flow.

12.2 Health Check Endpoint

The health check endpoint at localhost:4000/health returns the current status of the backend server and its dependencies (database, Redis). This is useful for monitoring uptime and diagnosing connectivity issues.

  1. Click the Health Check button (heartbeat icon) in the sidebar quick actions
  2. Or open http://localhost:4000/health directly in your browser
  3. The response shows server status, uptime, and connection states for MongoDB and Redis
  4. A green status indicator in the sidebar confirms the server is healthy
FieldDescription
statusOverall server health — "ok" means all systems operational
uptimeServer uptime in seconds since last restart
databaseMongoDB connection status — "connected" or "disconnected"
redisRedis connection status — "connected" or "disconnected"
